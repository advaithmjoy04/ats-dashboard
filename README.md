# ATS Platform

A production-ready **Applicant Tracking System (ATS)** designed for institutional placement management.

The platform allows:

* Admins to create job postings
* Recruiters to review applicants
* Students to apply for jobs
* Resume storage and management
* Email notifications
* Placement analytics

The system is designed with **secure and scalable architecture**.

---

# Tech Stack

Backend

* Node.js
* Express.js
* MongoDB (Mongoose)
* JWT Authentication

Frontend

* React.js
* React Router
* Axios

Infrastructure

* AWS EC2
* AWS S3
* MongoDB Atlas

---

# Development

Install dependencies

npm install

Run development server

npm run dev

Start production server

npm start
